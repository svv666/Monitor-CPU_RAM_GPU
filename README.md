# Monitor-CPU_RAM_GPU

Компактная панель мониторинга Windows поверх всех окон.
Показывает загрузку компьютера в реальном времени и не мешает работе.

ПОКАЗАТЕЛИ
- CPU: загрузка процессора в процентах
- RAM: занятая память в ГБ
- GPU: загрузка и температура видеокарты NVIDIA (или N/A)
- NET: скорость сети (в расширенном режиме)
- DISK: заполненность системного диска (в расширенном режиме)

РЕЖИМЫ
- Компактный: CPU, RAM, GPU
- Расширенный: плюс сеть и диск

ВОЗМОЖНОСТИ
- 4 темы: Dark Neon, Cyberpunk, Dracula, Minimalist
- Прозрачность: 100 / 90 / 80 / 70 / 50 %
- Обновление: 1 / 2 / 3 / 5 секунд
- Перетаскивание мышью и примагничивание к краям экрана
- Закрепление позиции
- Скрытие при полноэкранных приложениях
- Автозапуск с Windows
- Быстрый запуск диспетчера задач
- Фиксированный размер окна — не дёргается при смене цифр

УПРАВЛЕНИЕ
- Левая кнопка мыши — перемещение
- Правая кнопка мыши — меню настроек

ТЕХНИЧЕСКИ
- Windows 10/11,
- Сборка: PyInstaller (один exe, настройки в config.json рядом)
- Сеть не используется, телеметрии нет
